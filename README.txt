PARTY KNIGHT — Mimesis

Windows: double-click Start Party Knight.cmd with Node.js installed. Keep the server window open while playing.
Other systems: run npm start here and open http://127.0.0.1:4174/. No npm install is needed.
You can also serve this entire folder on a static HTTP server. The game needs WebGL 2.

W/S: move. A/D: turn. Shift: run. Drag: look. E: hold or release Stubby. Space: advance dialogue. Esc: pause.

Music: Mimesis. Painting: Misti Ogle. Third-party licenses and audio credits are in vendor/ and assets/.
